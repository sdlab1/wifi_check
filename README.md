# wifi-diagnostic

Bash-скрипт для комплексной диагностики Wi-Fi + интернет-соединения в Linux.

## Что делает

- Показывает драйвер, режим USB, сигнал, скорость
- Проверяет настройки энергосбережения и TCP/IP
- Пингует шлюз и список целей с прогрессом в одну строку
- Показывает потери по хопам через `mtr`

## Зависимости

- `inxi` — информация о железе
- `iw` — состояние Wi-Fi
- `mtr-tiny` — трассировка с потерями
- `iproute2` — ip, ss

Установка:
\`\`\`bash
sudo apt install inxi iw mtr-tiny iproute2
\`\`\`

## Использование

\`\`\`bash
chmod +x wifi-check.sh
./wifi-check.sh
\`\`\`

## Настройка

Отредактируйте переменные в начале скрипта:
- `PING_TARGETS` — список целей для ping
- `PING_COUNT` — количество пакетов на цель
- `MTR_TARGETS` — список целей для mtr

## Как читать результаты

Смотрите на `Loss%` в выводе mtr:
- **Хоп 1 (ваш роутер) >0%** — проблема в Wi-Fi
- **Хоп 2+ >0%** — проблема у провайдера/оператора

Также обратите внимание на разброс `Best` vs `Avg` в mtr:
- Если `Best` <50 мс, а `Avg` >500 мс — это **bufferbloat**
- Если `Best` и `Avg` оба высокие — слабый сигнал или перегрузка канала
